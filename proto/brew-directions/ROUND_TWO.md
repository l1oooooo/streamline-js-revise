# Current design constraints

Coffee extraction starts from the machine's physical group head. None of the prototype directions has a software Coffee / Brew coffee start button. The prototype toolbar switches to Brewing for inspection, and Resume only plays simulated readings.

The comparison contains four directions:

- Current: existing layout and materials, with the coffee-start control removed to match the hardware workflow.
- Studio: Focus's large recipe presentation and the original full-height cover with a small caption. The right cover is decorative and contains no profile controls. Profiles are selected on the left. Brewing retains Instrument's chart and telemetry.
- Sequence: keep preparation checks and chart-led brewing without the top numbered progress bar. The checks describe readiness and do not gate the physical group head.
- Panorama: retain horizontal favorite profiles, the profile preview, full-width brewing chart, and bottom readouts. Home's recipe dock contains only four recipe controls.

Rail was rejected and removed. No winner is selected or integrated. All work stays inside the isolated prototype directory; production files are unchanged.
